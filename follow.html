Follow my game

Follow my game lets the board analyzer keep up with your game by itself. You connect the game's log and share the game window on this page. When the log shows a move, this page takes a picture of the game and hands it to the board analyzer open in another tab, which reads the board and updates the advice. Everything happens in your browser, on your PC. Below, this page says exactly what it reads and what it sees, with the code that does each part. The code is loaded from the same files your browser runs, so it can't differ from what's described here.

    Triggers and log lines (testing)

      In short

      • Nothing before you agree. Until you agree at the bottom of this page, its controls stay hidden: nothing can open your log or see any window, and the board analyzer takes no pictures.
      • One file, read only. It reads the game log you pick (UE_game.log), and only the lines the game writes after you connect it. It can't open any other file, and it never changes the log.
      • One window, only with the log connected. It takes pictures of the one window you share, never a whole screen or a browser tab. It only does so while the game log is connected: when the log shows a move, or when you press Take a picture now. Nothing is recorded in between.
      • Pictures stay in your browser. This page hands each picture to the board analyzer open in another tab, which reads the board from it with the screenshot reader. The picture passes between the two tabs inside your browser. Pictures are kept as small previews in memory and are gone when you close the tabs. Follow my game never uploads a picture or your log.
      • Boards, only if you share boards. The board the analyzer reads from each picture is treated like any board you ask about. If board sharing is on (the switch under the analyzer's ask button), the board is shared for the odds study: its cells, day and tools, with no picture and nothing about you. Turn that switch off and nothing is shared.
      • Off whenever you like. Stop following and Stop sharing end it at once, as does your browser's own stop-sharing button. Turning it off at the bottom of this page stops it at once, and the analyzer stops taking pictures.

      What your browser asks you

      Chrome or Edge asks you twice, and nothing happens until you say yes both times:

      1. To open a file. You pick UE_game.log, in your Steam library under Torchlight Infinite\UE_game\TorchLight\Saved\Logs. The site gets read-only access to that one file. On your next visit, the browser asks again before the site can read it.
      2. To share a window. The browser lists your open windows, and you pick Torchlight: Infinite. Whole screens aren't offered. While the window is shared, the browser shows which one, with a button to stop.

      Browsers never tell a website which program a window belongs to: not its name, its title or its process. So the code can't check that the window is the game. What it does check is that you shared one window, not your screen or a browser tab, and the browser's sharing bar shows you which window that is. Pick the game, and only the game is seen.

      Other browsers can't follow a file on your PC, so Follow my game needs Chrome or Edge on a PC. Run the game borderless or windowed: in exclusive fullscreen, a shared window looks black.

      How it works, with its code

      Each step shows the code that does it, word for word, with its line numbers in the file. It's read from the site just now.

      1. Nothing runs before you agree

      When this page opens, it checks for your agreement first. Without it, the controls stay hidden, and none of the code that connects the log, shares a window or passes pictures to the analyzer is set up.

      The part that takes pictures checks again on its own, every time, right before each picture. A picture is taken only if three things hold: you agreed to this version of this page, the game log is connected and being read, and what's shared is a single window. Connecting the log or sharing a window without your agreement is refused too.

      2. You pick the log

      connectLog opens the browser's file picker, and the site gets only the file you choose. resumeLog is for later visits: the browser remembers your choice, but asks you again before the site may read it.

      3. It reads only the new lines

      Once a second, the follower checks whether the log has grown, and reads only the part added since its last look. It starts at the end of the log, so nothing written before you connected is ever read. Each new line is checked against the triggers below. A line that matches nothing is dropped; a line that matches the watch pattern is shown to you on the page. It runs in a background worker, so it keeps up when the tab is hidden.

      4. It watches for moves

      The triggers are patterns for the lines the game writes when something happens. Each has a kind, the pattern, and a settle time. The prison's lines are added once they're known; until then the defaults are the Frozen Canvas's, which test the whole path. You can see and change the triggers at the top of this page, under Triggers and log lines.

      When matching lines come in a burst, it waits until the log has been quiet for the settle time, so the animations finish. Then it takes one picture for the whole burst.

      5. It takes one picture of the window you shared

      connectWindow asks the browser to share a window, which you pick. useStream turns away a whole screen or a browser tab and stops that share at once. grab takes a single still frame, and only when the check from step 1 allows it. In Chrome and Edge, nothing plays the window as video in between.

      6. The picture goes to your board analyzer

      This page lists each picture as a small preview, then hands it to the board analyzer you opened from here, in another tab. It travels between the tabs inside your browser, through the browser's BroadcastChannel, which reaches only this site's own pages. If no analyzer tab is open, the picture is only listed here.

      7. The analyzer reads it into your board

      The analyzer answers only after you've agreed, and reads only the pictures sent to it. The screenshot reader, running in your browser, turns the picture into a board. A prompt shows you what it read and what would change, and waits: Use this board loads it and asks for advice, Skip drops it. If you turn on Use each reading without asking, it loads each reading straight away. Only how the reading went goes back to this page. Nothing is uploaded.
